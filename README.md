# Ma Timer

A clean Flutter Android screen-time dashboard and 25-minute Pomodoro focus timer.

Features:
- Today's usage dashboard
- Android Usage Access integration
- Unlock count and top apps
- 25-minute focus timer
- Seven-day trend
- Dark UI with neon green accents
- Custom Ma Timer launcher icon

Push to main/master or manually run Build Ma Timer Release APK in GitHub Actions. The workflow creates the Android project from a clean Flutter template, configures permissions, restores the app source, generates the launcher icon, builds the release APK, and uploads MaTimer-Release-APK.
